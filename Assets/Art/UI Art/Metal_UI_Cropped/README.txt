E.C.H.O — Cropped Metal UI sprites

All 15 PNG files have been losslessly cropped to the smallest rectangle containing nontransparent pixels.
The pixel colors and transparency of the artwork are unchanged.

Import into a NEW Unity folder (do not overwrite the original Metal UI package).
Do NOT copy the original .meta files: Unity should generate new import metadata/GUIDs.

Recommended Unity import settings:
  Texture Type: Sprite (2D and UI)
  Sprite Mode: Single
  Filter Mode: Point (no filter)
  Compression: None
  Mip Maps: Off (if displayed)

IMPORTANT: Cropping does not automatically configure 9-slice borders.
For resizable window frames, configure the correct border pixels in Sprite Editor and use Image Type: Sliced.
The window background and window border are separate elements; layer them if desired.
